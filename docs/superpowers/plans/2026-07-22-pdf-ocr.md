# OCR for Scanned PDFs — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let scanned/image-only PDFs (refused today) become packs, by rendering their pages and OCR'ing them with a bundled Tesseract subprocess, feeding the same page-locatored `build_pack` path §3b ships.

**Architecture:** Three units. `kpack-pdf` gains single-page rendering (pdfium). A new `src-tauri/src/ocr.rs` runs the bundled `tesseract` binary as a subprocess (mirrors the `llama-server` bundle-and-spawn pattern). `kpack.rs`'s scanned-PDF refusal branch becomes an orchestrator: partition text vs image pages, render→OCR image pages one at a time with progress, merge in page order, hand to `document_from_pages` unchanged.

**Tech Stack:** Rust (`pdfium-render =0.9.3`, `image`), Tesseract CLI (bundled prebuilt binary + `eng.traineddata`), Tauri, Node fetch script.

## Global Constraints

- **Printed English v1 only** — `tesseract -l eng`. No handwriting, no other languages.
- **Windows-first** — bundle + verify `tesseract.exe`; write fetch + path resolution per-OS but only exercise Windows in v1.
- **No new build toolchain** — Tesseract is a bundled prebuilt binary run as a subprocess (like `pdfium.dll`/`llama-server`), never linked. `pdfium-render` stays runtime-bound; keep the `=0.9.3` version pin and `pdfium_7881` ABI pin.
- **Installer under ~200 MB** — tesseract binary + `eng.traineddata` (fast) ≈ +20 MB.
- **Render DPI = 300.** One page resident at a time (render → OCR → drop).
- **Soft cap:** > 150 image pages → warn + proceed; > 500 → refuse (runaway guard).
- **Fail-closed:** missing tesseract binary → refuse (today's message), never a silent empty pack. Per-page OCR/render failure degrades that page to empty; never fails the build.
- **`extract_pages` and the text-layer / MD / TXT / DOCX / EPUB / HTML paths stay byte-identical.** OCR only runs on pages with no extractable text.
- **Locators stay `p.N`.** No schema change; `document_from_pages` is unchanged.

```rust
/// Render one 0-based page to PNG bytes at `dpi`. Single-page on purpose:
/// the caller renders → OCRs → drops one page before the next, bounding
/// memory to a single full-page bitmap. Reuses the process-global pdfium
/// binding (same [`pdfium`] OnceLock as [`extract_pages`]).
pub fn render_page(
    pdf_bytes: &[u8],
    page_index: usize,
    dpi: u16,
    pdfium_lib_path: &Path,
) -> Result<Vec<u8>, PdfError> {
    let pdfium = pdfium(pdfium_lib_path)?;
    let document = pdfium
        .load_pdf_from_byte_slice(pdf_bytes, None)
        .map_err(|e| PdfError::Parse(e.to_string()))?;

    let page = document
        .pages()
        .get(page_index as u16)
        .map_err(|e| PdfError::Parse(format!("page {}: {e}", page_index + 1)))?;

    // PDF page dimensions are in points (1/72 inch); target pixel width = points * dpi/72.
    let scale = dpi as f32 / 72.0;
    let target_w = (page.width().value * scale).round().clamp(1.0, 10_000.0) as u16;

    let config = PdfRenderConfig::new().set_target_width(target_w);
    let bitmap = page
        .render_with_config(&config)
        .map_err(|e| PdfError::Parse(format!("render page {}: {e}", page_index + 1)))?;
    let image = bitmap
        .as_image()
        .map_err(|e| PdfError::Parse(format!("image page {}: {e}", page_index + 1)))?;

    let mut png = Vec::new();
    image
        .into_rgb8()
        .write_to(&mut std::io::Cursor::new(&mut png), image::ImageFormat::Png)
        .map_err(|e| PdfError::Parse(format!("encode page {}: {e}", page_index + 1)))?;
    Ok(png)
}
```

```rust
//! On-device OCR for scanned PDF pages via a BUNDLED tesseract binary run as
//! a subprocess — the same "ship a prebuilt binary in resources/, spawn it,
//! never link it" pattern as `llama-server` (`inference.rs`) and the pdfium
//! dynamic library. Isolation: a tesseract hang is killed by the per-page
//! timeout; a tesseract crash can't take down the app.

use std::io::Write;
use std::path::PathBuf;
use std::process::Command;
use std::time::{Duration, Instant};

use tauri::{AppHandle, Manager};

/// Bundled tesseract lives in `resources/ocr/` alongside `resources/pdfium/`.
const OCR_RELATIVE_DIR: &str = "ocr";
/// Per-page OCR timeout — a runaway/looping tesseract on one page is killed
/// and that page degrades to empty rather than hanging the whole build.
const PER_PAGE_TIMEOUT: Duration = Duration::from_secs(60);

#[derive(Debug)]
pub enum OcrError {
    /// The bundled tesseract binary isn't present/runnable — OCR is off.
    Unavailable,
    /// Tesseract ran but failed (non-zero exit, timeout, unreadable output).
    Failed(String),
}

impl std::fmt::Display for OcrError {
    fn fmt(&self, f: &mut std::fmt::Formatter<'_>) -> std::fmt::Result {
        match self {
            OcrError::Unavailable => write!(f, "OCR is not available on this install"),
            OcrError::Failed(m) => write!(f, "OCR failed: {m}"),
        }
    }
}
impl std::error::Error for OcrError {}

fn tesseract_binary_name() -> &'static str {
    if cfg!(windows) { "tesseract.exe" } else { "tesseract" }
}

/// The bundled tesseract executable — mirrors `kpack::bundled_pdfium_path`.
pub fn bundled_tesseract_path(app: &AppHandle) -> PathBuf {
    crate::inference::resources_root(app)
        .join(OCR_RELATIVE_DIR)
        .join(tesseract_binary_name())
}

/// The bundled `tessdata` directory holding `eng.traineddata`.
pub fn bundled_tessdata_dir(app: &AppHandle) -> PathBuf {
    crate::inference::resources_root(app).join(OCR_RELATIVE_DIR).join("tessdata")
}

/// True iff the bundled tesseract binary is present — the app gates the OCR
/// path on this and falls back to the scanned-PDF refusal when false.
pub fn ocr_available(app: &AppHandle) -> bool {
    bundled_tesseract_path(app).is_file()
}

/// OCR one rendered page (PNG bytes) → recognized English text. Writes the
/// PNG to a unique scratch temp, runs `tesseract <tmp> stdout -l eng
/// --tessdata-dir <dir>`, returns stdout. Temp is removed on every path.
pub fn ocr_png(app: &AppHandle, png_bytes: &[u8]) -> Result<String, OcrError> {
    let bin = bundled_tesseract_path(app);
    if !bin.is_file() {
        return Err(OcrError::Unavailable);
    }
    // Unique temp under the OS temp dir; process id + a monotonic nanos-ish
    // counter keep concurrent builds from colliding.
    let tmp = std::env::temp_dir().join(format!(
        "cleophis-ocr-{}-{}.png",
        std::process::id(),
        Instant::now().elapsed().as_nanos() // strictly-increasing within a build loop
    ));
    let _guard = TempFile(tmp.clone());
    std::fs::File::create(&tmp)
        .and_then(|mut f| f.write_all(png_bytes))
        .map_err(|e| OcrError::Failed(format!("write temp: {e}")))?;

    let mut child = Command::new(&bin)
        .arg(&tmp)
        .arg("stdout")
        .arg("-l").arg("eng")
        .arg("--tessdata-dir").arg(bundled_tessdata_dir(app))
        .stdout(std::process::Stdio::piped())
        .stderr(std::process::Stdio::null())
        .spawn()
        .map_err(|e| OcrError::Failed(format!("spawn tesseract: {e}")))?;

    // Bounded wait: poll try_wait, kill on timeout.
    let start = Instant::now();
    loop {
        match child.try_wait() {
            Ok(Some(status)) => {
                if !status.success() {
                    return Err(OcrError::Failed(format!("tesseract exit {status}")));
                }
                break;
            }
            Ok(None) => {
                if start.elapsed() > PER_PAGE_TIMEOUT {
                    let _ = child.kill();
                    return Err(OcrError::Failed("timed out".into()));
                }
                std::thread::sleep(Duration::from_millis(50));
            }
            Err(e) => return Err(OcrError::Failed(format!("wait: {e}"))),
        }
    }
    let out = child.wait_with_output().map_err(|e| OcrError::Failed(format!("output: {e}")))?;
    Ok(String::from_utf8_lossy(&out.stdout).into_owned())
}

/// RAII cleanup for the scratch PNG — removed even on an early return/panic.
struct TempFile(PathBuf);
impl Drop for TempFile {
    fn drop(&mut self) {
        let _ = std::fs::remove_file(&self.0);
    }
}
```

> Note on the temp-name counter: `Instant::now().elapsed()` is near-zero; replace with a `std::sync::atomic::AtomicU64` static incremented per call for a guaranteed-unique suffix. (Implementer: use an `AtomicU64` `fetch_add` — `Instant` was shorthand.)

```rust
/// 0-based indices of pages whose text-layer extraction is empty/whitespace —
/// the image-only pages that need OCR. Mirrors `pdf_has_no_text`'s per-page
/// emptiness test, but returns WHICH pages rather than an all-empty bool.
fn image_page_indices(pages: &[(u32, String)]) -> Vec<usize> {
    pages.iter().enumerate()
        .filter(|(_, (_, text))| text.trim().is_empty())
        .map(|(i, _)| i)
        .collect()
}

#[derive(Debug, PartialEq, Eq)]
enum OcrBudget { None, Ok, Warn, Refuse }

/// Soft cap on OCR work: warn the user past 150 image pages, refuse past 500.
fn ocr_page_budget(image_page_count: usize) -> OcrBudget {
    match image_page_count {
        0 => OcrBudget::None,
        1..=150 => OcrBudget::Ok,
        151..=500 => OcrBudget::Warn,
        _ => OcrBudget::Refuse,
    }
}
```
