# Basic CI (tests, secret scan, audits) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run GitHub Actions on both repos. Tests run on every PR into `main` and every push to `main`, and they block. A secret scan and dependency audits run alongside and do not block. No secrets and no publishing are involved.

**Architecture:** There are two independent tracks, one per repository. Each track works in its own worktree on branch `sdd/ci-basic`, branched from the open PR head.
- **Track T (cleophas-triage):** test-hygiene fixes, then a `ci.yml` that reads a pinned public mobile commit, then `security.yml` with the gitleaks config.
- **Track M (cleophis):** `ci.yml` plus a path-filtered `rust.yml`, then `security.yml` with the gitleaks config, then hardening of the existing `mobile-check.yml`.
- **Order:** the two tracks run in parallel. Tasks within a track run in order, because they share one worktree.
- **The end:** a final controller task re-runs the clean-clone simulation and fast-forwards the PR branches. **It does not push.** Pushing is the founder's go/no-go.

**Tech Stack:** GitHub Actions YAML; bash; pwsh for Windows steps; Python 3.10 with pytest; Node 20.19.2 (`node --test`); Rust 1.97.1 (cargo); gitleaks 8.30.1, cargo-audit 0.22.2, pip-audit 2.10.1, actionlint 1.7.12.

**Spec:** `docs/superpowers/specs/2026-10-05-ci-basic-design.md`, in this repo at `sdd/ci-basic`, commit 8b1efc9. Implementers read the spec and this plan together.

## Review Focus

Spec-implied failure modes that no unit test exercises. Each one is pinned by a step in the task named.
1. **Malformed or missing `.github/mobile-pin`.** The pytest job must fail loudly with a clear error, never fall back to testing some other mobile commit. Task T2, Step 4.
2. **A failing pytest piped through `tee`.** The step must still fail (`set -o pipefail`). Task T2, Step 5.
3. **gitleaks range on edge events.** Branch creation (`before` = 40 zeros), a force-push (`before` not in history), a PR, and schedule/dispatch must each give a valid scan range. Task T3, Step 5 and Task M2, Step 5.
4. **`rust.yml` path filter missing an out-of-tree build or test input** (e.g. `contracts/*.toml` via `include_str!`, or `tools/reference/` used by the reference-pack test). A change that breaks the build must trigger the workflow. Task M1, Step 2.
5. **Fork PRs on the public repo.** Every workflow must work with no secrets and a read-only token. Enforced by `check_workflows.py` (R4/R5) in every workflow task, and by Task F, Step 2.

    branches: [main]

permissions:
  contents: read

concurrency:

jobs:
  node:
    runs-on: ubuntu-latest
    timeout-minutes: 15
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          persist-credentials: false
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: '20.19.2'
      - name: node --test probes/
        run: node --test probes/

    runs-on: ubuntu-latest
    timeout-minutes: 45
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          path: triage
          persist-credentials: false

      # The mobile commit these tests read is pinned in a tracked file and moves
      # only in a deliberate commit. A malformed pin fails here, loudly; CI never
      # falls back to testing some other mobile commit.
      - name: Read .github/mobile-pin
        id: pin
        run: |
          sha="$(head -n1 triage/.github/mobile-pin | tr -d '[:space:]')"
          if ! printf '%s' "$sha" | grep -Eq '^[0-9a-f]{40}$'; then
            echo "::error file=.github/mobile-pin::expected one full 40-hex commit SHA on line 1, got '${sha}'"
            exit 1
          fi
          echo "sha=${sha}" >> "$GITHUB_OUTPUT"

      # Public repo: no token needed. Full history, because tests read pinned
      # historical commits with `git show <commit>:<path>`.
      - name: Check out shojuro/cleophis at the pin
        uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
        with:
          repository: shojuro/cleophis
          ref: ${{ steps.pin.outputs.sha }}
          path: mobile
          fetch-depth: 0
          persist-credentials: false

      # Some pytest tests shell out to node (they skip without it); match local.
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: '20.19.2'

      - uses: actions/setup-python@5fda3b95a4ea91299a34e894583c3862153e4b97 # v7.0.0

        working-directory: triage

          CLEOPHIS_MOBILE_ROOT: ${{ github.workspace }}/mobile

          set -o pipefail
          python -m pytest -q -rs --ignore=work -p no:cacheprovider 2>&1 | tee "$RUNNER_TEMP/pytest.out"

      # Coverage CI cannot reach (git-ignored work/ archives, founder-machine
      # worktrees, uncached tokenizers) is listed rather than silent.
      - name: Skip summary
        if: always()
        run: |
          python3 - "$RUNNER_TEMP/pytest.out" >> "$GITHUB_STEP_SUMMARY" <<'PY'
          import collections, re, sys
          try:
              lines = open(sys.argv[1], encoding="utf-8", errors="replace").read().splitlines()
          except FileNotFoundError:
              print("## pytest\n\nNo pytest output: the run did not start.")
              sys.exit(0)
          pat = re.compile(r"^SKIPPED \[(\d+)\] [^:]+(?::\d+)?: (.*)$")
          counts = collections.Counter()
          for line in lines:
              m = pat.match(line)
              if m:
                  counts[m.group(2)] += int(m.group(1))
          final = [l for l in lines if re.search(r"\b\d+ (passed|failed)\b", l)]
          print("## pytest\n")
          if final:
              print(f"`{final[-1].strip('= ')}`\n")
          print(f"**{sum(counts.values())} skipped**, by reason:\n")
          print("| count | reason |\n|---:|---|")
          for reason, n in counts.most_common():
              print(f"| {n} | {reason.replace('|', '/')} |")
          PY
